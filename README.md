# AI 캐릭터 스튜디오 (웹 MVP)

🌐 **https://hyungd0.github.io/ai-character-studio/**

배포: 이 폴더가 GitHub 저장소 `HyungD0/ai-character-studio`이고, `main` 브랜치에 push하면 GitHub Pages에 자동으로 반영됩니다(1분 안팎).
새 도메인에서 쓰려면 카카오 JavaScript SDK 도메인과 Firebase 승인된 도메인에 그 주소를 추가하세요.

Unity 수업 프로젝트를 웹으로 옮긴 버전입니다. 서버·API 키 없이 동작합니다.

## 기능
- **사진 한 장으로 캐릭터 만들기**: 이름·호칭·성격(다정/츤데레/장난/차분)·첫인사. 이 기기 브라우저(localStorage)에 저장됩니다.
- **표정 변화**: 표정별 사진을 넣으면 그 사진으로 바뀌고, 없으면 기본 사진에 색감·움직임·볼터치·이모지 효과를 입힙니다.
  (Unity 버전에서 사진 한 장을 넣으면 표정이 안 바뀌던 문제의 웹 해결책)
- **심심이식 대화**: `chat-db.js`의 키워드 DB와 구글 시트에서 답을 찾습니다. 모르는 말이면 "대답 가르쳐 주기" 버튼이 뜨고, 가르친 답은 이 기기에 바로 반영되며 시트에는 `pending`(검수 대기)으로 쌓입니다.
- **호감도**: 대화에 따라 오르내립니다.
- **사진 편집기**: 캐릭터·표정·배경 사진을 고르면 드래그로 위치, 슬라이더/휠/두 손가락으로 확대·축소. 투명 PNG/WebP는 투명도를 유지합니다(투명 배경 권장).
- **표정 이미지**: 기본 5가지(중립·기쁨·슬픔·당황·화남) 칸을 눌러 넣고 ✕로 지움. "＋ 표정 추가"로 이름을 직접 붙인 표정을 5개까지 더 만들 수 있고, AI 대화에서 그 표정을 골라 씁니다. 기본 캐릭터 하루의 사진·표정도 바꿀 수 있습니다.
- **말투**: 프리셋 버튼(다정함·츤데레·장난꾸러기·차분함)으로 채우거나 직접 글로 씁니다. 말투와 캐릭터 설정은 글자 수 제한이 없습니다. 다만 공유할 때는 사진까지 합쳐 문서 하나가 900KB 안에 들어와야 하고, 글이 길수록 AI 호출 비용이 늘어납니다.
- **자동 저장**: 만들기/수정 화면은 입력할 때마다 저장되어 나갔다 와도 이어서 쓸 수 있고, 대화 기록(캐릭터별 최근 60개)과 AI 설정·키(서비스별로 따로)도 다음 접속 때 그대로 남습니다.
- **캐릭터별 배경과 설정**: 배경 사진과 "캐릭터 설정" 글(AI 대화용)을 캐릭터마다 저장하고 공유합니다.
- **AI 실시간 대화 (선택)**: 홈의 "🤖 AI 실시간 대화 설정" 또는 대화 화면 왼쪽 위 칩에서 AI 서비스를 고르고(Gemini 기본 / OpenAI / Claude) 자기 API 키를 넣으면, 키워드 대화 대신 AI가 캐릭터 설정대로 대답합니다.
  - 키는 그 브라우저에만 저장됩니다("기억하기"를 끄면 탭을 닫을 때 삭제). 서버나 공유 링크에는 올라가지 않으므로, 공유받은 사람은 자기 키를 넣어야 AI 대화가 됩니다.
  - 오류가 나면 자동으로 기본(키워드) 대화로 대답합니다.
  - 모델 이름은 서비스마다 자주 바뀌므로 설정 화면에서 직접 고칠 수 있습니다.
- **금칙어 필터**: 입력·학습·이름에 적용됩니다. (한국어·영어·중국어)
- **3개 국어 (한국어 · English · 中文)**: `i18n.js`에 화면 문구가 언어별로 있습니다.
  - 언어 결정 순서: 직접 고른 언어 > 브라우저 언어 > 접속 국가(IP) > 영어. 홈 오른쪽 위 🌐에서 바꿀 수 있습니다.
  - 접속 국가는 중계 서버의 `GET /geo`가 Cloudflare 정보로 나라 코드만 알려 줍니다(IP는 저장하지 않음). 하루 동안 기억합니다.
  - 공유 버튼이 나라에 맞게 바뀝니다: 한국 카카오톡·인스타, 일본·대만·태국 LINE·X, 중화권 WeChat(QR)·微博, 그 밖 WhatsApp·X·Facebook. QR 코드는 어디서나 쓸 수 있습니다.
  - 기본 대화는 상대가 쓴 글자(한글/영어/한자)를 보고 그 언어의 DB(`chat-db.js`)에서 대답합니다. AI 대화는 상대가 쓴 언어로 대답합니다.
- **방문 통계 (Google Analytics 4)**: `config.js`의 `gaMeasurementId`(밤티 계정 속성 ai-character-studio-fd38a, `G-BFJEDT5S4T`). `analytics.js`가 화면 종류(home/create/edit/chat/shared_link)와 언어, `create_character`·`share`(method)·`ai_chat_on` 이벤트만 보냅니다. 캐릭터 이름·대화·공유 id는 보내지 않고, localhost에서는 꺼집니다.
- **공개 갤러리 · 댓글**: 공유 창에서 "공개 갤러리에 올리기"를 켜면 `gallery/{캐릭터id}`에 이름·첫인사·작은 사진만 올라가고, 홈의 "🌏 둘러보기"에서 인기/최신순으로 보여요. 공개 캐릭터의 대화 화면에는 💬 댓글(100자, 쓴 사람·캐릭터 주인·관리자가 삭제 가능)이 있어요.
- **관리 화면 (`#/admin`)**: `config.js`의 `adminUids`와 `firestore.rules`의 `isAdmin()`에 등록된 기기(익명 로그인 uid)에서만 신고 목록 보기·캐릭터 삭제·신고 무시가 됩니다. 다른 기기에서 열면 그 기기 ID가 보이니, 바꾸려면 두 곳에 넣고 규칙을 다시 게시하세요.
- **출석·호감도 이벤트**: 하루 한 번 대화방에 오면 출석(연속 3일 +2, 7일 +3)과 오늘의 질문, 호감도 20·40·60·80%를 처음 넘을 때 특별 대사.
- **이 설정으로 만들기**: 받은 캐릭터의 말투·설정·표정 이름을 가져와 내 사진으로 새 캐릭터를 만듭니다.
- **앱 설치(PWA)**: `manifest.webmanifest` + `sw.js`(항상 최신 파일 우선, 오프라인일 때만 저장본).
- **개인정보·이용 안내 (`#/privacy`)**: 3개 국어.
- **최신 정보 검색 (Gemini만)**: AI 설정에서 켜면 Google 검색 그라운딩을 쓰고 출처와 검색 추천을 대답 아래에 보여 줍니다(실제 키로는 아직 미확인).
- **좋아요 · 랭킹**: 공개 캐릭터에 기기마다 한 번 ❤️(`gallery/{id}/likes/{uid}` + 숫자 `likes`). 둘러보기의 "❤️ 이번 주"(월요일 0시 한국 시간에 초기화, `weekKey`·`weekLikes`)와 "🏆 전체" 랭킹. 숫자는 보안 규칙이 1씩만 오르내리게 검사합니다.
- **오늘의 대화 미션**: 캐릭터마다 하루 3개(메시지 5번, 기쁘게 하기, 설레게 하기, 오늘의 질문에 대답, 대답 가르치기, 대화 카드, 호감도 3, 긴 메시지 중). 하나에 💗+2, 모두 끝내면 +3.
- **기념일 · 생일**: 대화 화면에 "💞 N일째". 7·30·50·100·200·300·365·500·730·1000일째에 특별 대사와 💗+5. 캐릭터 생일(만들기 화면)에도 축하 대사.
- **캐릭터 단톡방 (`#/groups`)**: 캐릭터 2~4명을 한 방에. AI 키가 있으면 이름이 불린 캐릭터부터 최대 3명이 서로의 말을 보고 대답하고, "▶ 캐릭터끼리 대화시키기"로 세 마디 주고받습니다. 키가 없으면 각자 기본 대화로 대답하되, 만든 사람이 AI를 공유한 받은 캐릭터는 1:1 대화처럼 중계 서버(그 사람의 키, 캐릭터별 하루 한도)로 대답합니다. 기록은 이 기기에만(방마다 100개).
- **사용법 튜토리얼**: 처음 방문하면 5단계 안내가 뜨고(언어 선택 포함), 홈의 "❓ 사용법"으로 다시 볼 수 있습니다.

python -m http.server 8080 --directory web

## 구글 시트 연결 (선택)
1. 새 구글 스프레드시트 → 확장 프로그램 → Apps Script
2. `apps-script/Code.gs` 내용을 붙여넣고 저장
3. 배포 → 새 배포 → 유형 "웹 앱", 실행 계정 "나", 액세스 "모든 사용자" → 배포
4. 나온 `/exec` 주소를 `config.js`의 `sheetUrl`에 넣습니다.
5. 시트 "대화"에 쌓인 행 중 괜찮은 것의 **상태** 칸을 `approved`로 바꾸면 모든 사용자에게 반영됩니다.

## 캐릭터 공유 (Firebase, 무료 Spark 요금제)
대화 화면의 📤 버튼을 누르면 중계 서버의 `/s/<id>` 링크가 만들어집니다. 카톡·SNS 미리보기에는 그 캐릭터의 이름·첫인사·얼굴(공유 문서의 `preview`, 없으면 `photo`)이 뜨고, 사람은 앱의 `?c=<id>`로 바로 이동합니다. 이전에 복사한 `?c=<id>` 링크도 그대로 열리지만 미리보기는 기본 이미지입니다. 링크를 연 사람은 그 캐릭터와 대화할 수 있고(수정 불가), "나도 만들기" 버튼으로 자기 캐릭터를 만들 수 있습니다.

- 사진은 Firestore 문서 안에 압축해서 저장합니다. Firebase Storage는 유료 요금제가 필요해서 쓰지 않습니다. 문서 하나가 1MB를 넘지 않도록 자동으로 줄입니다.
- 익명 로그인을 사용해서, 만든 사람(같은 브라우저)만 수정하거나 공유를 중지할 수 있습니다.
- 새 캐릭터 등록은 기기(익명 계정)당 하루 20개까지입니다. 횟수는 `userLimits/{uid}` 문서에 캐릭터 등록과 함께 기록되고 보안 규칙이 검사합니다. `web/cloud.js`의 `MAX_NEW_PER_DAY`와 `firestore.rules`의 `maxNewPerDay()`를 같게 유지하세요.
- 공유되는 항목은 이름, 성격, 첫인사, 사진입니다. 호칭(만든 사람 이름)과 호감도는 공유되지 않습니다.
- 받은 사람에게는 🚩 신고 버튼이 있고, 신고는 Firestore `reports` 컬렉션에 쌓입니다.

설정 방법:
1. https://console.firebase.google.com 에서 프로젝트 만들기 (Google Analytics는 꺼도 됨)
2. **빌드 → Firestore Database** → 데이터베이스 만들기 (위치 `asia-northeast3` 서울, 프로덕션 모드)
3. **Firestore → 규칙** 탭에 `firebase/firestore.rules` 내용을 붙여넣고 게시
4. **빌드 → Authentication** → 시작하기 → 로그인 방법에서 **익명** 사용 설정
5. 프로젝트 설정(⚙) → 내 앱 → 웹 앱(`</>`) 추가 → 나오는 `firebaseConfig` 객체를 `config.js`의 `firebase:`에 붙여넣기
6. 배포한 뒤 **Authentication → 설정 → 승인된 도메인**에 사이트 주소를 추가 (예: `아이디.github.io`)

Firebase 설정이 비어 있으면 **localhost에서만** "개발용 가짜 서버"(이 브라우저 저장소)로 공유 흐름을 시험할 수 있습니다. 이때 링크는 같은 브라우저에서만 열립니다.

## AI 대화 공유 (중계 서버, Cloudflare Workers 무료)
만든 사람이 공유 창에서 **"받은 친구도 내 AI 키로 실시간 대화하게 하기"**를 켜면, 링크를 받은 친구도 AI 대화를 할 수 있습니다.
- 키는 친구 브라우저로 가지 않고 중계 서버(`relay/worker.js`, `https://ai-character-relay.bamtistudio.workers.dev`)에만 AES-GCM으로 암호화되어 저장됩니다.
- 등록과 해제는 Firebase 익명 로그인 토큰과 Firestore 문서의 `ownerUid`를 확인해 **만든 사람만** 할 수 있습니다.
- 캐릭터마다 하루 한도(30/100/300/1000회 또는 직접 입력, 최대 10000회)가 있고, 넘으면 친구는 기본 대화로 전환됩니다.
- 프롬프트는 서버가 캐릭터 문서로 직접 만들기 때문에 친구가 키를 다른 용도로 쓸 수 없습니다.
- 수정 방법: Cloudflare 대시보드 → Workers 및 Pages → ai-character-relay → 코드 편집에 `relay/worker.js` 내용을 붙여넣고 배포합니다. KV 바인딩 이름은 `RELAY`, D1 바인딩 이름은 `DB`입니다.
- 하루 대화 횟수는 D1(무료: 하루 쓰기 10만 행)에 셉니다. 표는 자동으로 만들어지고 지난 날짜 기록은 자동으로 지워집니다. D1을 연결하지 않으면 KV로 세며, 이때는 KV 무료 쓰기 한도 때문에 전체 하루 약 1,000회까지만 됩니다.
